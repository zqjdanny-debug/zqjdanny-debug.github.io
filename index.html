GmailPy

A personal desktop email client for Gmail.

GmailPy is a private Windows desktop application used by its owner to read, organize and send messages in their own Gmail account through the official Gmail API. It is not offered as a public service and is not distributed to other users.

The application runs entirely on the user's own computer. It requests access only after the user signs in with Google and grants permission, and it never sends mailbox data to any server other than Google's.
