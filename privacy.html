GmailPy Privacy Policy

Last updated: November 10, 2026

What GmailPy is

GmailPy is a personal desktop email client that runs on the user's own Windows computer and accesses the user's own Gmail account through the Gmail API, after the user explicitly authorizes it with Google OAuth.

Data accessed

With the gmail.modify permission, GmailPy reads messages, labels and mail settings (such as the signature and display name) so they can be shown in the application, changes labels when the user archives, stars, deletes or marks messages, and sends messages the user writes.

How data is stored and shared

  • Mailbox data is fetched directly from Google and displayed on the user's computer. Message contents are not stored on disk by the application, apart from temporary files the user explicitly saves.
  • The OAuth token is stored only on the user's computer, encrypted with Windows DPAPI.
  • No data is sent to the developer or to any third party. There are no analytics, advertising or tracking.
  • Data is never sold, transferred for advertising, or used to train any model.

Google API Services User Data Policy

GmailPy's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Removing the account inside GmailPy also deletes the locally stored token.

Contact

Questions about this policy can be sent to the support email listed on the application's Google consent screen.
